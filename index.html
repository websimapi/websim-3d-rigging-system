Skeleton Tools

Bone Mode ON: Click on model to add new bones. Click an existing bone to select it as the parent for the next bone you create.
Bone Mode OFF: Click a bone to select it. The 'Transform Tools' panel below will become active, allowing you to pose the selected bone using on-screen gizmos.

Transform Tools

Active when 'Bone Mode' is OFF and a bone is selected.
Use the on-screen gizmos (visual handles) to translate or rotate the selected bone.
Click the buttons above to switch between Translate and Rotate gizmos.
